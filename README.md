Fix Your Moments — photography studio marketing site, built with [Next.js](https://nextjs.org) App Router.

This project uses **pnpm**. Do not use npm or yarn — only `pnpm-lock.yaml` is checked in.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to load Bodoni Moda (headings) and Outfit (body/UI).

See `PRD.md`, `Architecture.md`, `Rules.md`, `phases.md` and `Design.md` for the full project specification.
